# MensagemMySQL

Aplicação desenvolvida em Java para gerenciamento de mensagens, com integração a banco de dados SQL e implementação de operações CRUD.

O projeto foi desenvolvido com o objetivo de praticar conceitos de programação Java, persistência de dados e interação com banco de dados.

## 🚀 Tecnologias

* Java
* MySQL
* Oracle
* JDBC
* SQL

## 📋 Sobre o projeto

O `MensagemMySQL` é uma aplicação Java voltada para o gerenciamento de mensagens armazenadas em banco de dados.

A aplicação trabalha com operações de:

* Inserção de mensagens
* Consulta de registros
* Alteração de mensagens
* Exclusão de mensagens

O projeto utiliza conexão com banco de dados para realizar a persistência das informações.

## 🏗️ Conceitos utilizados

Durante o desenvolvimento foram aplicados conceitos importantes de desenvolvimento backend, como:

* Programação Orientada a Objetos
* Conexão com banco de dados
* JDBC
* SQL
* Operações CRUD
* Persistência de dados
* Manipulação de registros

## 🗄️ Banco de dados

O projeto foi desenvolvido com suporte a bancos de dados relacionais, utilizando principalmente:

* MySQL
* Oracle

A aplicação utiliza comandos SQL para realizar as operações de manipulação dos registros.

### Operações CRUD

```text
CREATE
  ↓
Inserção de mensagens

READ
  ↓
Consulta de mensagens

UPDATE
  ↓
Alteração de mensagens

DELETE
  ↓
Exclusão de mensagens
```

## 💻 Como executar

### Pré-requisitos

Antes de executar o projeto, é necessário possuir:

* Java instalado
* MySQL ou Oracle configurado
* Banco de dados criado
* Credenciais de acesso ao banco configuradas

### Clonando o projeto

```bash
git clone https://github.com/gustavoconce/MensagemMySQL.git
```

Entre na pasta:

```bash
cd MensagemMySQL
```

Configure a conexão com o banco de dados de acordo com o ambiente utilizado.

Depois, execute a aplicação através da IDE ou ferramenta de build configurada para o projeto.
